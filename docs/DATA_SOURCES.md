# Источники данных
| Данные | Источник | Статус в UI |
|---|---|---|
| Онлайн/карта сервера | A2S_INFO (UDP, query-порт сервера) | Подтверждено источником |
| Поиск серверов | Steam Web API GetServerList (ключ) или мастер-сервер Valve (UDP) + A2S_INFO | Подтверждено источником |
| Игроки сервера (ник, время по данным сервера) | A2S_PLAYER (UDP); список может быть скрыт или неполон | Подтверждено / «сервер не отдаёт список» |
| История присутствия | локальные опросы A2S в SQLite | Оценка по опросам, не игровое время |
| Статус профиля Steam | Steam Web API GetPlayerSummaries (ключ пользователя) | Подтверждено источником |
| Нахождение в Rust | поле gameid; если его нет — «неизвестно», не «не в игре» | Подтверждено / Недоступно |
| Сервер игрока | поле gameserverip, только если Steam его вернул | «По данным Steam» |
| Карта, команда, метки, устройства | Rust+ (Facepunch Companion API), по подключению к вашему серверу | Подтверждено сервером |
| Карта сервера на RustMaps, монументы, слои | RustMaps.com (ваш ключ API; сопоставление по размеру и seed, по названию через BattleMetrics или Server Search сайта) | Данные сервиса; слои — картинки сайта |
| Таймеры РТ/Deep Sea/вертолёт/Bradley | ввод пользователя | Оценка |
| Гниение строительных объектов | ввод пользователя + линейная модель (справочные значения, настраиваются) | Оценка |
| Чинук / вертолёт / аэрдроп | ручные нажатия кнопок, медиана интервалов | Оценка по наблюдениям |
| Bradley | кнопка «Bradley уничтожен» + интервал, заданный пользователем для сервера | Оценка |

О программе (версия, автор, источники): раздел «О программе» в приложении.

«Нет ответа» от сервера ≠ «сервер выключен». Интервалы респавна не зашиты — задаются пользователем.
