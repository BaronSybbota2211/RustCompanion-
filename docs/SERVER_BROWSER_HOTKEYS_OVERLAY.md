# Поиск сервера, горячие клавиши, оверлей

Источники, протокол A2S, статусы списка игроков и ограничения описаны в `docs/PLAYER_MONITORING.md`. Здесь — поведение интерфейса.

## Поиск сервера
Ввод с задержкой 400 мс (быстрый набор = один запрос, предыдущие отменяются), минимум 2 символа. Ответ на более ранний запрос не перезапишет более новый.
Состояния: загрузка, результаты, «Серверы не найдены» (не ошибка), ошибка с кнопкой «Повторить». Можно ввести `ip:порт запросов` — будет прямой запрос A2S_INFO. Пустое поле показывает недавние серверы (хранятся локально).
Клавиатура: ↓/↑ — выбор, Enter — открыть, Esc — закрыть. Сервер идентифицируется адресом запросов `host:port`.
Команда подключения: `net.connect IP:PORT` формируется только из валидных IPv4/hostname и игрового порта (из данных A2S_INFO); порт запросов за игровой не выдаётся, при неизвестном порте показывается «Адрес подключения недоступен».

## Выбор сервера и мониторинг
- Выбор сервера открывает его мониторинг: сразу запрашиваются A2S_INFO и A2S_PLAYER, показываются ник, время на сервере по данным сервера («не сообщено», если его нет) и расчётное присутствие по локальной истории.
- Сервер сохраняется локально и выбирается во вкладке «Наблюдение»; там же — список игроков онлайн с кнопкой «В наблюдение». Кнопка «Следить» в поиске добавляет игрока в тот же список.
- Кнопка «История» показывает локальную историю наблюдений сервера (первое/последнее обнаружение, расчётное время, число заходов); «Сессии» — историю выбранного ника.

## Игроки сервера
Список обновляется вручную и автоматически (по умолчанию 30 с, не чаще 15 с). При смене сервера прежний список очищается сразу, запрос прежнего сервера отменяется, запоздавший ответ отбрасывается.
Состояния: загрузка, список, «сейчас нет игроков», «сервер не отдаёт список игроков», «нет ответа», ошибка (при ошибке показываются последние данные с пометкой «устарело»), неполный список (получено N из M).
«Следить» добавляет игрока в существующий мониторинг (3 успешные проверки подряд с полным списком → событие «не обнаружен»; ошибки сети и скрытый/неполный список не считаются). Уведомление включается на вкладке «Уведомления» (по умолчанию выключено).

## Горячие клавиши
Глобальные (RegisterHotKey, права администратора не нужны, MOD_NOREPEAT против автоповтора). Назначаются пользователем, значений по умолчанию нет.
Требуется Ctrl/Alt/Win либо F-клавиша; конфликты внутри приложения и недопустимые сочетания отклоняются с объяснением; если Windows/другое приложение уже заняли сочетание — показывается причина,
остаётся кнопка «Отметить сейчас». События: Чинук, патрульный вертолёт, Bradley (появление), аэрдроп, грузовой корабль.
Нажатие = одна отметка (защита от удержания 0,8 с; вторая отметка того же события ближе 10 с отклоняется; при переводе системных часов назад отметка не пишется).
Отметки привязаны к серверу, выбранному на вкладке; без сервера отметка не записывается, и это сказано явно. Прогноз: уже по двум отметкам (один интервал, «низкая уверенность»),
с третьего интервала — медиана. Предупреждение за N минут (по умолчанию 10) — отдельное событие в «Уведомлениях», по умолчанию выключено.
Отметки можно удалить (последнюю) или сбросить историю события.
Примечание: Bradley «после уничтожения» (отсчёт от кнопки уничтожения) и Bradley «появление» (интервалы между вашими отметками) — разные модули с разной историей.

## Оверлей: что исправлено и как проверить
Возможные причины, из-за которых прежний оверлей мог быть не виден (без запуска на Windows первопричину **подтвердить нельзя**):
1. Не было постоянной панели — окно показывалось только при событии уведомления, а все уведомления по умолчанию выключены.
2. Позиция считалась только по основному монитору; при игре на втором мониторе окно оказывалось вне видимой области.
3. Окно один раз получало Topmost и могло оказаться под другими topmost-окнами; теперь `SetWindowPos(HWND_TOPMOST, NOACTIVATE)` повторяется каждую секунду, результат и код ошибки пишутся в диагностику.
4. Эксклюзивный полноэкранный режим Direct3D: обычное окно в нём не отображается принципиально — теперь определяется через `SHQueryUserNotificationState` и объясняется.
Сделано: постоянная панель (HUD) с выбранными элементами и обратным отсчётом; режим перемещения/изменения размера и «закрепить» (клики насквозь); позиция и размер сохраняются; проверка, что сохранённая позиция видима на текущих мониторах (иначе — угол);
кнопка «Проверить оверлей» (создано ли окно, видимость, стили NOACTIVATE/TRANSPARENT, размер, DPI, число мониторов, запущен ли Rust, режим экрана) и запись в журнал.
Ручная проверка: «Оверлей» → «Показывать панель» + выбрать элементы → «Тестовая плашка» → «Проверить оверлей»; Rust в Borderless/Windowed.
Горячая клавиша показа/скрытия оверлея не реализована (скрыть: чекбокс или пункт «Скрыть оверлей» в меню трея).

## Оверлей на мониторе с Rust
Опция «Показывать оверлей и плашки на мониторе, где открыто окно Rust» (включена по умолчанию, вкладка «Оверлей»).
- Приложение находит окно клиента `RustClient.exe` (только положение окна, без доступа к памяти игры), берёт монитор с наибольшим пересечением и ставит оверлей в выбранный угол его рабочей области.
- Если сохранённая позиция панели лежит на мониторе с Rust, она сохраняется; если на другом — оверлей переносится на монитор с Rust.
- Раз в секунду проверяется, не перенесли ли вы Rust на другой монитор; новая плашка всегда появляется на текущем мониторе игры. В режиме перемещения оверлей не прыгает.
- Если окно Rust не найдено (игра не запущена, окно ещё не создано, свёрнуто) — используется сохранённая позиция или основной монитор; причина видна в «Проверить оверлей» и в журнале.
- Координаты монитора, окна Rust и оверлея берутся в одной системе пикселей Windows (EnumDisplayMonitors / GetWindowRect / SetWindowPos); позиция панели теперь хранится в пикселях.
- Ограничения: определение идёт по имени процесса `RustClient` и видимому главному окну; в эксклюзивном полноэкранном режиме Direct3D оверлей всё равно не виден; на мониторах с разным масштабом DPI положение приблизительное (проверить можно только на вашем ПК).

## Внешний вид
Единая тёмная тема (`Theme.xaml`): тёмные выпадающие списки, поля, флажки, полосы прокрутки, тонкие карточки, один акцент. Исправлена ошибка прежней версии: ключ ресурса `Muted` был объявлен дважды (кисть и стиль) — приложение не загрузило бы словарь.
