# Поиск серверов и наблюдение за игроками (Steam Query) — источники, ограничения, настройка

Приложение **не использует** BattleMetrics, Rust Metrics и другие платные/сторонние агрегаторы. Данные берутся напрямую у Steam и самих серверов, бесплатно.

## Источники
| Задача | Источник | Примечание |
|---|---|---|
| Поиск по названию | 1) Steam Web API `IGameServersService/GetServerList` (нужен бесплатный ключ из «Настроек»); 2) без ключа — мастер-сервер Valve по UDP (`hl2master.steampowered.com:27011`, фильтр `\appid\252490\name_match\*текст*`), каждый найденный адрес проверяется A2S_INFO | до 30 результатов, мастер-сервер ограничен по частоте |
| Поиск по адресу | ввод `ip:порт запросов` — прямой A2S_INFO | порт запросов часто не равен игровому (Rust: обычно `server.queryport`) |
| Данные сервера | A2S_INFO (UDP): название, карта, онлайн; для Rust онлайн/максимум/очередь берутся из тегов `cp`/`mp`/`qp` (поля протокола — один байт, до 255) | |
| Игроки | A2S_PLAYER (UDP): ник и время подключения, как его сообщил сервер | SteamID протоколом не передаётся |

## Как работает A2S в приложении
- Запрос A2S_INFO (`FF FF FF FF 54 "Source Engine Query\0"`); если сервер отвечает challenge (`0x41`), запрос повторяется с ним.
- Запрос A2S_PLAYER (`FF FF FF FF 55` + challenge, начальное значение `0xFFFFFFFF`); ответ-challenge обрабатывается автоматически (не более 3 раундов).
- Ответы, разбитые на части (`FE FF FF FF`, id, всего/номер частей), собираются в любом порядке; повторы и части чужого запроса игнорируются; число частей и итоговый размер ограничены. Ответы, сжатые bzip2, не поддерживаются — показывается ошибка.
- Тайм-аут одной попытки — половина «Тайм-аута запроса» (2–6 с), две попытки на запрос. Пауза между запросами — «Пауза между A2S-запросами» (≥200 мс).
- Отмена: смена сервера или закрытие панели отменяет текущий запрос; запоздавший ответ прежнего сервера отбрасывается. Все сетевые вызовы асинхронные — UI не блокируется.

## Статусы списка игроков (никогда не «фиктивный пустой список»)
| Статус | Смысл |
|---|---|
| Список получен | ники получены полностью (в пределах допуска 5%) |
| На сервере нет игроков | сервер сообщает онлайн 0 и отдал пустой список |
| Сервер не отдаёт список | онлайн > 0, но список пуст или без ников — сервер скрывает игроков; список **не** выдаётся за «игроков нет» |
| Список неполный | получено меньше, чем онлайн, или ответ оборван — показано то, что пришло |
| Нет ответа на A2S_PLAYER | INFO отвечает, PLAYER — нет |
| Ошибка | ответ не по протоколу |
«Нет ответа» на запрос ≠ «сервер выключен»: порт запросов может быть закрыт, неверен или заблокирован. Ограничения сервера не обходятся.

## История наблюдений (локальная SQLite, таблица `presence_history`)
Каждый успешный опрос с реально полученным списком записывает ники: первое обнаружение, последнее обнаружение, число опросов и **расчётное** время присутствия (сумма интервалов между опросами, где ник был виден подряд). Пауза между опросами больше 4 минут начинает новый заход.
Это **нижняя оценка по моментам опроса**, а не игровое время: игрок мог зайти раньше первого опроса и выйти позже последнего. Время, которое сообщает сам сервер (колонка «На сервере»), показывается отдельно и приложением не проверяется.
Наблюдения копятся только пока приложение открыто и сервер выбран в поиске или находится под наблюдением.

## Правило выхода
«Выход подтверждён» — после N (по умолчанию 3) последовательных успешных опросов с **полным** списком, где ника нет, при условии что игрок ранее был подтверждённо на сервере. Ошибки сети, тайм-ауты, скрытый или неполный список счётчик не увеличивают (статус «неизвестно»).
Ключ события (`игрок:эпизод:exit`) записывается в БД до отправки, поэтому перезапуск не создаёт дубликатов. Уведомление показывает время последнего подтверждённого присутствия и время обнаружения выхода (не точное время выхода).

## Ограничения A2S
- Нет SteamID: игрок определяется по нику; смена ника = новый игрок, одинаковые ники на сервере неразличимы.
- Многие серверы (и большинство крупных) скрывают список игроков или режут его; список может быть усечён до размера одного пакета.
- Время в A2S_PLAYER сообщает сервер и оно может быть неточным (на части серверов — время с вайпа/перезапуска или 0).
- UDP не гарантирует доставку; возможны потери, поэтому есть повторы и статусы.
- Поиск без ключа Steam опирается на мастер-сервер Valve: ограничен по скорости, может возвращать неполный набор.
- Rust+ / игровой чат: не реализовано.

## Настройка
1. (Необязательно) бесплатный ключ Steam Web API в «Настройках» — быстрый поиск по названию.
2. Telegram: бот через @BotFather → токен и Chat ID в «Настройках».
3. Discord: Параметры канала → Интеграции → Вебхуки → URL в «Настройках».
Секреты хранятся зашифрованными (DPAPI), в экспорт, БД и логи не попадают.

## Миграция данных
Миграция v7: старые идентификаторы серверов BattleMetrics заменяются адресом `host:port`, записи наблюдения сохраняются по нику, недавние серверы очищаются. Старые токены BattleMetrics в хранилище секретов больше не читаются.
