# Безопасность
- Нет чтения памяти, инъекций, обхода EAC и автоматизации игры.
- Steam API-ключ хранится зашифрованным через Windows DPAPI (CurrentUser), не попадает в БД и логи; URL-логирование HttpClient отключено, сообщения проходят Redactor.
- Минимальные паузы между запросами к источникам (rate limiter), тайм-ауты, нижние границы интервалов опроса.
- Запросы только к адресам, которые указал пользователь, и к api.steampowered.com по HTTPS.
