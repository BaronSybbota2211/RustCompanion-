## Структура
- `src/RustCompanion.App` — Windows WPF-интерфейс.
- `src/RustCompanion.Core` — основная логика приложения.
- `src/RustCompanion.RustPlus` — адаптер Rust+.
- `src/ThirdParty/RustPlusApi` — сторонняя библиотека Rust+ API.
- `tests/RustCompanion.Tests` — автоматические тесты.

Документация описывает опубликованное состояние проекта. Возможности,
зависящие от внешних серверов и протоколов, могут изменяться.
